# 🎵 GestureBeat

GestureBeat is a browser-based gesture-controlled music visualizer built with MediaPipe Hand Landmarker.

## Features

- ✋ Real-time hand tracking
- 🎵 Music synchronization
- ✨ Gesture-triggered effects
- 📹 Webcam support
- 🎬 Video recording
- 🌐 GitHub Pages ready

## Tech Stack

- JavaScript
- Vite
- MediaPipe Tasks Vision
- Canvas API
- Web Audio API

## Run

```bash
npm install
npm run dev
